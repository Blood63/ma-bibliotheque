Bibliothèques

Deux bibliothèques séparées (par exemple une par personne) : chacune a ses livres, séries, statistiques et objectifs. Le choix de la bibliothèque affichée est mémorisé sur cet appareil.

Objectifs de lecture

Pour la bibliothèque affichée (change-la avec le sélecteur en haut). Tous les types et formats comptent (livres, mangas, BD, papier ou Kindle…). Les lectures « Lu (avant) » ne comptent pas dans l’objectif.

Sauvegarde

Les données restent sur cet appareil (stockage local du navigateur) et, si tu l’actives, dans ton gist GitHub secret. Exporte de temps en temps un fichier JSON.

Format CSV accepté

Séparateur « ; » ou « , ». Colonnes reconnues (ligne d’en-tête obligatoire, ordre libre) : Type ; Titre ; Auteur ; Série ; Tome ; ISBN ; Genre ; Statut ; Lu ; Date lu ; Note ; Notes ; Couverture ; ID. Type = Livre, Manga, BD ou Autre ; Statut = Possédé ou Liste d’envies ; Lu = oui/non ; Date lu = MM/AAAA (le mois de lecture ; JJ/MM/AAAA et AAAA-MM-JJ sont aussi acceptés). Avec la colonne ID (présente dans l’export), les livres existants sont mis à jour au lieu d’être dupliqués.

Synchronisation (GitHub Gist privé)

Partage la bibliothèque entre tes téléphones, ta tablette et tes ordinateurs via un gist secret sur ton compte GitHub. Fusion automatique : rien n’est écrasé, les suppressions sont reportées. Le même jeton que pour Suivi Montagne fonctionne (fichier séparé ma-bibliotheque-data.json).

Comment ça marche / créer le jeton

Tu as déjà un jeton pour Suivi Montagne ? Réutilise-le : colle-le ici (ou touche le bouton 🔑 s’il apparaît) puis « Enregistrer et synchroniser ». Un second gist secret, ma-bibliotheque-data.json, est créé à côté de celui de Suivi Montagne ; les deux apps ne se mélangent pas.

Sinon, créer un jeton (2 minutes) :

  1. Ouvre ce lien en étant connecté à GitHub : créer un jeton « Ma bibliothèque ».
  2. La note et la case gist sont déjà remplies. Ne coche rien d’autre.
  3. Expiration : « No expiration » (ou 1 an ; il faudra alors refaire un jeton à l’échéance).
  4. Tout en bas, clique sur le bouton vert Generate token.
  5. Copie le jeton (il commence par ghp_). GitHub ne l’affiche qu’une fois : garde-le dans ton gestionnaire de mots de passe.
  6. Colle-le ici puis touche Enregistrer et synchroniser. Le premier appareil crée le gist secret.
  7. Sur chacun de tes autres appareils (2 téléphones, tablette, 2 ordinateurs) : ouvre l’app → ⚙️ Réglages → colle le même jeton → Enregistrer et synchroniser. Le gist est retrouvé et les données fusionnées.

Fusion : chaque livre a un identifiant ; si le même livre a été modifié sur deux appareils, la modification la plus récente gagne. Une suppression est mémorisée et reportée partout. Hors ligne, tout fonctionne : la synchro se fera dès le retour d’internet.

Sécurité : le jeton reste sur l’appareil et n’est envoyé qu’à api.github.com. Il ne donne accès qu’à tes gists et n’est jamais inclus dans les exports. Pour le révoquer : github.com → Settings → Developer settings → Personal access tokens. Un jeton « fine-grained » marche aussi s’il a uniquement la permission « Gists : Read and write ».

Aide

Ajouter un livre avec l’ISBN ou le code-barres

L’ISBN est le numéro à 13 chiffres sous le code-barres (978… ou 979…). Tape-le puis 🔎 : titre, auteur et couverture sont remplis via Open Library, puis Google Books. Le bouton 📷 scanne le code-barres avec la caméra sur les navigateurs qui le permettent (Chrome sur Android, Chrome/Edge sur ordinateur). Sur iPhone/iPad (Safari) le scan n’est pas disponible : tape simplement l’ISBN. La recherche ISBN demande internet.

Mangas : ajouter toute une série

Choisis le type Manga, indique la série (ex. One Piece) et l’auteur, coche « Ajouter plusieurs tomes d’un coup » puis tomes 1 à 20. Les tomes déjà présents sont ignorés. Dans Séries, touche un tome pour le marquer lu et fixe le nombre total de tomes pour voir ceux qui manquent.

Lectures par mois

Le bouton ✓ compte la lecture dans le mois en cours ; tu peux choisir un autre mois (et l’année) dans la fiche du livre — pas besoin du jour exact. Pour les livres lus il y a longtemps, choisis « Lu (avant) » : ils comptent dans le total et le % de lus, mais pas dans les statistiques mensuelles ni l’objectif. Pour en marquer plusieurs d’un coup : Bibliothèque → bouton de sélection, ou Séries → « Tout Lu (avant) ».

Installer sur l’écran d’accueil

Android/Chrome : menu ⋮ → « Ajouter à l’écran d’accueil » / « Installer l’application ». iPhone/iPad : bouton Partager → « Sur l’écran d’accueil ». Ordinateur : icône d’installation dans la barre d’adresse. L’app fonctionne ensuite hors ligne.
